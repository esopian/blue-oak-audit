# blue-oak-audit

CLI tool that audits npm dependencies against the Blue Oak Council license quality ratings.

## Tech Stack

- TypeScript (strict mode), ESM-only (`"type": "module"`)
- Build: tsup (bundles `src/cli.ts` → `dist/cli.js`)
- Tests: vitest
- Target: Node 18+

## Commands

```bash
npm run build        # Build to dist/
npm run dev          # Watch mode rebuild
npm run typecheck    # tsc --noEmit
npm test             # Run tests (auto-creates fixtures via pretest)
npm run test:watch   # Watch mode tests
```

## Project Structure

```
src/
  cli.ts             # CLI entry point (commander-based)
  audit.ts           # Core audit orchestration
  config.ts          # Config loading from package.json + CLI flags
  dependencies.ts    # Reads node_modules for dependency info
  licenses.ts        # SPDX license parsing and normalization
  ratings.ts         # Maps licenses to Blue Oak Council tiers
  types.ts           # Shared TypeScript types
  formatters/        # Output formatters (table, json, summary)
test/
  *.test.ts          # Vitest test files
  fixtures/          # Auto-generated test fixture projects
  setup-fixtures.sh  # Creates fixture node_modules for tests
```

## Conventions

- All source is ESM (`import`/`export`, no `require`)
- CLI binary has `#!/usr/bin/env node` banner (added by tsup)
- Test fixtures are generated by `test/setup-fixtures.sh` and run automatically via the `pretest` script
- Only `dist/` is published to npm (controlled by `"files"` in package.json)

## Agentic Behavior

- Always run `npm run typecheck` and `npm test` before committing changes
- Run `npm run build` before testing CLI behavior manually
- The `prepublishOnly` script runs typecheck and build automatically before `npm publish`
